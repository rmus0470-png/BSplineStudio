B-Spline Studio for FreeCAD

About the Project

B-Spline Studio is an open-source FreeCAD add-on designed to provide a comprehensive graphical control panel for creating, editing, and manipulating B-spline curves.

The project is developed collaboratively by a human project director and OpenAI's ChatGPT AI.

Human-directed, AI-assisted development.

The human project director oversees development, establishes requirements, evaluates functionality, tests implementations, and determines the project's direction.

ChatGPT assists with programming, interface design, documentation, troubleshooting, and implementing new features.

Project Goals

Our objective is to simplify B-spline editing by bringing scattered FreeCAD controls into one accessible graphical interface.

Planned capabilities include:

- Numerical editing of individual control points.
- Control-point insertion and removal.
- Knot, weight, and degree management.
- Interactive curve visualization.
- Parametric relationships with other sketch geometry.
- Integration with FreeCAD Sketcher and Part Workbenches.
- Live updates to dependent geometry.

Development Philosophy
